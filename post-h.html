Don't take our word for it. Check the stamp.

A free Observe stamp that shows this connector was checked — so you can run it with clearer eyes.

A trust stamp is only worth something if you can check it without asking us. Here's what checking an LDTT stamp looks like:

  1. Open the stamp file that ships with the connector. It's small and readable. Example stamp file.
  2. Read the level. Observe means telemetry in, nothing out to the aircraft.
  3. Match the build. Recompute the digest of the connector you have. If it doesn't match the stamp, the stamp doesn't cover it.
  4. Check the signature. The stamp is keyless-signed by our public GitHub workflow and logged in a public transparency log.
  5. Check the revoke list. It's signed and refreshed automatically. If the stamp is on it, stop.

The fields and rules behind each step are in the Stamp Spec v0.2 and the stamp schema.

If any step fails, treat the connector as unstamped. That's the whole point: the stamp works the same way no matter who's checking or which platform you're on.

Our first stamp also lists its own weak spots, so you know what isn't proven yet. Read that post.
