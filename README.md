# LDTT site

Live at **https://ldttstamp.org** (GitHub Pages; www redirects to the apex).

Public site for **Linked Drone Tool Trust (LDTT)**, a portable trust stamp for drone software connectors.

Spec, schema, and reference connector live in [rockmed888-ship-it/ldtt](https://github.com/rockmed888-ship-it/ldtt).

LDTT stamps connectors only. It does not certify aircraft, operators, airworthiness, or flight safety, and makes no FAA or other regulatory claim.
