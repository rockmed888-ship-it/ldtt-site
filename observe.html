LDTT Observe — software connectors

What Observe is

Observe is the first trust level. It is meant to show the connector was checked for the Observe bar: declared what it can touch, stayed in a read-oriented scope, and can be cut off if revoked. It is about the connector software, not flight clearance.

What you get when stamped

  • A portable stamp artifact tied to a connector (not an aircraft or pilot).
  • Declared Observe scope — read-oriented / telemetry observe limits.
  • A path to verify fields and provenance per Spec — see How it works.
